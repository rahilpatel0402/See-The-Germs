# See the Germs

Makes contamination chains visible on staged video of care tasks, for post-acute infection control.

It is a staff training and infection-prevention audit aid for staged or consented video. It does not diagnose, treat, or advise patients, and it gives no clinical recommendation about any person; the coaching note is workplace practice feedback for a caregiver, grounded in published hand-hygiene guidance. It is not surveillance. All footage is staged, synthetic, and contains no real patients or real facilities.

Built during the Meta Global AI Developer Hackathon, Oct 26 to Nov 4, 2026.
