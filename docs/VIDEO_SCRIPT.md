# Video script (three minutes hard cap)

Narration is generated, not recorded, and the screen is recorded by a scripted browser, so the cut is reproducible to the second. Each line starts a beat after the previous one ends; the shot list follows the narration's timing. Written for judges without a clinical background.

Each visual is explained before it happens: the what-if is introduced as a question, clip B shows the rub with its counter before the pathogen switch, and the sources appear on screen when the rule is named. Narration lines run 17 to 27 s and the shot list follows their timing.
